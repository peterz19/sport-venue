# 产品总览（当前已落地）

> 更新：2026-07-28  
> 定稿依据：收银 `b-end-sales/01` · 组织经营 `b-end-org/01` v1.1 · SaaS `saas/00`  
> 范围：**平台多商户运营** + **商户 B 端经营** + **C 端 API（mock 微信）**

---

## 1. 产品目标

1. **平台**：开户多家商户、启停、配置功能开关与微信渠道，数据互相隔离  
2. **商户组织经营**：多员工登录；收银/订场可归因；片场半小时互斥；球队对接与赛果排行  
3. **轻量收银**：无库存；选品 → 收款（现金 + 扫码占位）→ 日报  
4. **C 端能力**：顾客在商户自有小程序登录后订场、充值（当前为 mock 联调，非真微信）

---

## 2. 角色与权限

### 2.1 平台管理员（Admin）

| 能力 | 说明 |
|------|------|
| 登录 | 仅 `ADMIN`，入口 Admin 前端 |
| 商户开户 | 创建商户 + 老板账号；可选首场馆 |
| 启停商户 | 停用后该商户下账号无法登录 |
| 商户详情 | 概况、功能开关、微信渠道、审计 |
| 场馆管理 | 平台侧按商户筛选 CRUD |

### 2.2 商户老板 / 店员（B 端）

| 能力 | 老板 OWNER | 店员 STAFF |
|------|:----------:|:----------:|
| 员工增改/停用/重置密码 | ✅ | ❌ |
| 商品 / 片场 / 球队 / 订场 / 赛果 | ✅ | ✅ |
| 收银 | ✅ | ✅ |
| 看全员工业绩 / 全店销售 | ✅ | ❌ |
| 看自己业绩 / 本人销售 | ✅ | ✅ |
| 配置微信 Secret / 平台开关 | ❌（平台 Admin） | ❌ |

映射：老板 → `B_MERCHANT`；店员 → `B_STAFF`；均绑定 `merchant_id`。

### 2.3 C 端顾客

| 能力 | 说明 |
|------|------|
| 登录 | 小程序 `appId + code`（本地 mock）→ 绑定到该商户 |
| 可见 | 本商户场馆/片场、本人订场、本人余额与流水 |
| 订场 | 与 B 端同一片场库存互斥；不计员工业绩 |
| 支付 | 先充值再订场扣余额（MOCK 充值） |

```text
收银台 · 商品管理 · 销售报表 · 订单明细
订场日历 · 订场列表 · 赛果管理
```

### 3.2 平台 Admin（:3000）

```text

商户管理：列表 / 开户 / 编辑 / 启停 / 详情
  └ 详情：功能开关 · 绑定小程序 · 审计时间线 · 跳转场馆

```

### 3.3 C 端

当前**无独立小程序工程**；能力以 API `/c/**` 提供，供后续小程序对接。

## 4. 关键业务规则

- **收银业绩**：只算操作员工  
- **订场业绩（B）**：操作单量 + 对接单量（球队快照）；散客无对接业绩  
- **C 订场**：`source=C`；默认不计员工业绩  
- **互斥**：同片场时间重叠且状态为 `BOOKED`/`COMPLETED` → 禁止；`EXPIRED`/`CANCELLED` 不占场  
- **取消**：仅 `BOOKED`；已完成/已有赛果不可取消；C 取消可退余额  
- **过期**：定时任务将过结束时间的 `BOOKED` → `EXPIRED`  
- **赛果**：主客队须为本商户系统球队；一订场一赛果  
- **租户隔离**：B 端 `merchantId` 只信 JWT；C 端由小程序 `appId` 路由商户  
- **功能开关**：关闭收银/订场/球队/C 端等后，对应 API 返回 `40303`
