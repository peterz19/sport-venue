# 产品总览（当前已落地 B 端）

> 对应定稿：收银 `b-end-sales/01` · 组织经营 `b-end-org/01` v1.1  
> 范围：商户端经营（收银 + 员工 + 片场订场 + 球队 + 赛果 + 业绩）

---

## 1. 产品目标

让一家商户从「单账号操作」升级为「组织经营」：

1. 多名员工登录，收银/订场可归因到人  
2. 片场按半小时互斥订场，可选球队或散客  
3. 球队绑定对接员工，历史订场保留对接快照  
4. 订场可录赛果，形成球队排行  
5. 轻量收银（无库存）：选品 → 收款 → 日报

## 2. 角色与权限

| 能力 | 老板 OWNER | 店员 STAFF |
|------|:----------:|:----------:|
| 员工增改/停用/重置密码 | ✅ | ❌ |
| 商品 / 片场 / 球队 / 订场 / 赛果 | ✅ | ✅ |
| 收银 | ✅ | ✅ |
| 看全员工业绩 / 全店销售 | ✅ | ❌ |
| 看自己业绩 / 本人销售 | ✅ | ✅ |

映射：老板 → `users.userType=B_MERCHANT`；店员 → `B_STAFF`。

---

## 3. 功能模块（用户可见）

```text
收银台 · 商品管理 · 销售报表
订场日历 · 订场列表 · 赛果管理
片场管理 · 球队管理 · 球队排行榜
我的业绩 · 员工业绩（老板） · 员工管理（老板）
我的场馆 · 数据看板
```

### 关键规则摘要

- **收银业绩**：只算操作员工  
- **订场业绩**：操作单量（谁下单）+ 对接单量（球队对接快照）；散客无对接业绩  
- **订场互斥**：同片场时间重叠且状态为已预订/已完成 → 禁止  
- **取消**：仅「已预订」可取消并释放；已完成/已有赛果不可取消  
- **赛果**：主客队都必须是本商户系统内球队；一订场一赛果，可修正
