# 运维手册 · 本地部署与排错

> 面向开发/实施：把当前已落地的 B 端（venue + merchant）在本机跑起来。

---

## 1. 环境要求

| 项 | 建议 |
|----|------|
| JDK | **21**（勿用过高版本，以免 Lombok 编译失败） |
| Maven | 3.8+ |
| Node.js | 18+（商户端） |
| MySQL | 8.x，库名 `sport_venue` |
| Redis | 本地可用（venue 依赖） |

本机若用 Homebrew OpenJDK 21，可：

```bash
export JAVA_HOME=/opt/homebrew/Cellar/openjdk@21/21.0.7/libexec/openjdk.jdk/Contents/Home
export PATH="$JAVA_HOME/bin:$PATH"
```

（版本号以本机 Cellar 实际路径为准。）

---

## 2. 数据库初始化

```bash
# 按需执行（已有库可跳过建库）
mysql -uroot -p sport_venue < sport-venue-venue/src/main/resources/db/V3__sales_module.sql
mysql -uroot -p sport_venue < sport-venue-venue/src/main/resources/db/V4__org_booking_module.sql
mysql -uroot -p sport_venue < sport-venue-venue/src/main/resources/db/seed_merchant_user.sql
```

说明：

- `local` 配置若开启 JPA `ddl-auto: update`，缺表时也可能自动补齐，但仍建议执行官方 DDL，字段注释更完整。  
- 种子账号：`merchant001` / `123456`，`merchant_id=1`，角色老板。  
- 需已有可用场馆（`venues.merchant_id=1`），否则片场/订场无法选场馆。

数据库账号以 `sport-venue-venue/src/main/resources/application-local.yml` 为准。

## 3. 启动服务

### 3.1 场馆服务（后端）

```bash
export JAVA_HOME=...   # JDK 21
cd sport-venue-venue
mvn spring-boot:run -Dspring-boot.run.profiles=local -DskipTests
```

健康检查：

```bash
curl -s http://localhost:8082/api/health
```

期望：HTTP 200。Swagger 一般在 `http://localhost:8082/api/swagger-ui.html`（以实际配置为准）。

### 3.2 商户前端

```bash
cd sport-venue-merchant
npm install   # 首次
npm run dev
```

访问：http://localhost:3001  
Vite 已将 `/api` 代理到 `http://localhost:8082`。

### 3.3 端口占用

```bash
lsof -ti :8082 | xargs kill -9   # 慎用：结束占用 8082 的进程
```

## 4. 冒烟检查清单

1. 老板登录成功，顶栏显示角色「老板」  
2. 商品录入 → 收银台现金支付 → 销售报表有数据  
3. 新建店员 → 店员登录 → 无员工管理菜单  
4. 建片场 → 订场日历下单 → 重叠时段被拒 → 取消后可再订  
5. 建两支球队 → 球队订场 → 换对接人 → 历史单对接快照不变  
6. 录赛果 → 排行榜积分变化  
7. 「我的业绩」出现收银与订场指标  

更完整的业务操作见：`操作手册-商户端.md`。

## 5. 日志与排错

| 问题 | 排查 |
|------|------|
| 编译失败（Lombok） | 确认 `java -version` 为 21 |
| 启动报连不上 Config Server | local 可忽略（会打 Connection refused 日志），只要最终 Tomcat started |
| 401/登录失效 | 清浏览器 `localStorage.merchantInfo` 后重登 |
| 接口 500 且提示 PathVariable 参数名 | Controller 须写 `@PathVariable("id")`；已按此规范编写 |
| 订场冲突不符合预期 | 查 `bookings` 是否仍有 `BOOKED/COMPLETED` 占用同片场时段 |
| 前端请求失败 | 确认 8082 健康检查 OK；看浏览器 Network 的 `/api/...` |

后端日志：运行 `mvn spring-boot:run` 的终端输出。
