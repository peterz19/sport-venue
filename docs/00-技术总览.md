# 技术总览（当前已落地 B 端）

> 详细设计见各子目录技术方案；本文只做索引与落地对照。

---

## 1. 运行时组件

| 组件 | 说明 | 本地默认 |
|------|------|----------|
| `sport-venue-venue` | B 端业务主服务（商品/销售/员工/片场/订场/球队/赛果） | `:8082`，`context-path=/api`，profile=`local` |
| `sport-venue-merchant` | 商户端 Vue3 | `:3001`，代理 `/api` → `8082` |
| MySQL | 库 `sport_venue` | 见 `application-local.yml` |
| Redis | 会话/缓存（服务依赖） | 本地需可用 |

鉴权：商户 JWT（`/auth/merchant/login`）；B 端接口前缀 `/business/**`；`SecurityUtils` 取当前商户与老板/店员。

建议 JDK：**21**（更高版本可能与 Lombok 编译冲突）。

---

## 2. 核心表

| 表 | 用途 | DDL |
|----|------|-----|
| `products` / `sales_orders` / `sales_order_items` / `sales_payments` | 收银 | `V3__sales_module.sql` |
| `courts` | 片场 | `V4__org_booking_module.sql` |
| `teams` / `team_audit_logs` | 球队 + 审计 | V4 |
| `bookings` | 订场（含 `source`/`customer_user_id` 预留） | V4 |
| `match_results` | 赛果（一订场一单） | V4 |
| `users` | 员工账号（`B_MERCHANT`/`B_STAFF` + `merchant_id`） | 既有 |

占用冲突：同 `court_id`，时间区间相交，且 `status ∈ {BOOKED, COMPLETED}`。

## 3. API 一览（均需 JWT）

| 前缀 | 模块 |
|------|------|

| `/business/teams/**` | 球队 |

细节见：`b-end-sales/02`、`b-end-org/03`、`b-end-org/04`。
