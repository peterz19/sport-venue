## 1. 运行时组件

| 组件 | 说明 | 本地默认 |
|------|------|----------|
| `sport-venue-venue` | 业务主服务：B 端 + 平台商户 + C 端 API | `:8082`，`context-path=/api`，profile=`local` |
| `sport-venue-merchant` | 商户端 Vue3 | `:3001`，代理 `/api` → `8082` |
| `sport-venue-admin` | 平台 Admin Vue3 | `:3000`，代理 `/api` → `8082` |
| MySQL | 库 `sport_venue` | 见 `application-local.yml` |
| Redis | 服务依赖（缓存等） | 本地需可用 |

建议 JDK：**21**（更高版本可能与 Lombok 冲突）。

### 鉴权模型

| 入口 | 路径 | 角色 | 租户来源 |
|------|------|------|----------|
| 平台登录 | `POST /auth/login` | 仅 `ADMIN` | 无 |
| 商户登录 | `POST /auth/merchant/login` | `B_MERCHANT`/`B_STAFF` | `User.merchantId`；校验商户 `ACTIVE` |
| C 登录 | `POST /c/auth/wx-login` | `C_USER` | `appId` → `merchant_wx_channels` |
| B 业务 | `/business/**` | 仅 B 角色（**禁止 ADMIN**） | JWT → DB User → `merchantId` |
| 平台业务 | `/merchants/**`、`/venues/**` | 仅 `ADMIN` | 路径参数指定商户 |
| C 业务 | `/c/**`（除 auth/notify） | `C_USER` | `CustomerPrincipal.merchantId` |

JWT claims：`userId`、`userType`（C 端 subject 为 `c_{id}`）。过滤器按类型加载 `User` 或 `CustomerUser`。

配置要点（`application-local.yml`）：

```yaml
saas:
  crypto.key: ...           # Secret AES 密钥
  wx.mock-enabled: true     # C 登录 mock openid
  booking.expire-delay-ms: 300000
```

## 2. 核心表

### 2.1 B 端既有

| 表 | 用途 | DDL |
|----|------|-----|
| `merchants` / `users` / `venues` | 商户、账号、场馆 | 既有 |
| `products` / `sales_*` | 收银 | `V3__sales_module.sql` |
| `courts` / `teams` / `team_audit_logs` | 片场、球队 | `V4__org_booking_module.sql` |
| `bookings` | 订场（`source` B/C，`customer_user_id`） | V4 |
| `match_results` | 赛果 | V4 |

占用：同 `court_id`，时间相交，且 `status ∈ {BOOKED, COMPLETED}`。

### 2.2 SaaS / C 端（V5）

| 表 | 用途 |
|----|------|
| `platform_audit_logs` | 平台操作审计 |
| `merchant_features` | 功能开关与配额 |
| `merchant_wx_channels` | 小程序/公众号 AppId+加密 Secret |
| `merchant_wx_pay` | 微信支付商户配置 |
| `customer_users` | C 端顾客 |
| `user_wx_identities` | appId+openid 绑定 |
| `customer_wallets` / `wallet_ledgers` / `wallet_recharge_orders` | 余额与充值 |
| `merchant_commission_rules` | 商户抽成比例与渠道开关 | V6 |
| `platform_commission_entries` | 抽成明细（待结/已结） | V6 |
| `platform_commission_settlements` | 结算单 + snapshot_json | V6 |

DDL：`V5__saas_module.sql`、`V6__platform_commission.sql`  
本地亦可用 JPA `ddl-auto: update` 自动建表。

## 3. API 一览

### 3.1 认证与健康

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/auth/login` | 平台 ADMIN |
| POST | `/auth/merchant/login` | 商户；停用商户 → `40301` |
| POST | `/c/auth/wx-login` | C：`{appId,code}` |
| GET | `/health` | 健康检查 |

### 3.2 平台（ADMIN）

| 前缀 | 说明 |
|------|------|
| `/merchants` | 列表、详情、开户、改资料、改状态 |
| `/merchants/{id}/overview` | 概况聚合 |
| `/merchants/{id}/audits` | 审计 |
| `/merchants/{id}/features` | 功能开关 GET/PUT |
| `/merchants/{id}/wx-channels` | 微信渠道 GET/PUT（Secret 不回显） |
| `/merchants/{id}/wx-pay` | 支付配置 |
| `/admin/commissions/**` | 平台抽成规则、应收汇总、结清快照 | ✅ A1 台账 |
| `/venues/**` | 平台场馆管理 |

### 3.3 商户 B 端（JWT）

| 前缀 | 模块 | 功能开关 |
|------|------|----------|
| `/business/products/**`、`/business/sales/**` | 商品/收银 | `enableCashier` |
| `/business/bookings/**`、`/business/courts/**` | 订场/片场 | `enableBooking` |
| `/business/teams/**`、`/business/matches/**` | 球队/赛果 | `enableTeamMatch` |
| `/business/staff/**`、`/business/performance/**` | 员工/业绩 | — |
| `/business/venues/**`、`/business/dashboard/**` | 场馆/看板 | — |
| `/business/features` | 本商户开关只读 | — |

### 3.4 C 端

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/c/venues`、`/c/courts` | 本商户资源 |
| GET | `/c/courts/{id}/slots` | 可订时段 |
| POST | `/c/bookings` | 个人订场（可扣余额） |
| GET | `/c/bookings/mine` | 我的订场 |
| POST | `/c/bookings/{id}/cancel` | 取消并退余额 |
| GET | `/c/wallet`、`/c/wallet/ledger` | 余额/流水 |
| POST | `/c/wallet/recharge` | MOCK 充值即时入账 |
| POST | `/c/pay/notify/mock` | 幂等确认支付 |

旧路径 `/customer/**`：**denyAll**（未租户化，已禁用）。

## 4. 后端包约定

`com.sportvenue.venue`：

- `entity` / `repository` / `dto/**`  
- `service` + `impl`（含 `CAuthService`、`CBookingService`、`WalletService`、`MerchantFeatureService`）  
- `controller`：`Business*`、`MerchantController`、`CEndController`、`AuthController`  
- `config`：`SecurityConfig`、`JwtAuthenticationFilter`、`MerchantFeatureInterceptor`  
- `security.CustomerPrincipal`、`util.SecurityUtils` / `SecretCrypto`  
- `job.BookingExpireJob`

前端：

- 商户：`sport-venue-merchant/src`  
- Admin：`sport-venue-admin/src`（商户列表含详情抽屉：开关/微信/审计）

## 5. 安全与错误码

| code | 含义 |
|------|------|
| 401 | 未登录 |
| 403 | 角色不符 |
| 40301 | 商户已停用 |
| 40302 | 账号已停用 |
| 40303 | 功能未开通 |
| 404 | 资源不存在或不属于本租户 |
| 409 | 订场时段冲突 |
| 40201 | 余额不足 |

跨租户详情统一倾向 **404**。
