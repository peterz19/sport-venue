# 操作手册 · 商户端

> 适用：老板 / 店员  
> 地址：http://localhost:3001  
> 默认老板账号：`merchant001` / `123456`

---

## 1. 登录与角色

1. 打开商户端登录页，输入账号密码。  
2. 顶栏显示：商户名 · 姓名 · 角色标签（老板/店员）。  
3. **老板**可见：员工管理、员工业绩。  
4. **店员**不可见上述菜单；强制访问会被收回银台。

首次部署需执行种子或自行创建 `B_MERCHANT` 用户（见运维手册）。

---

## 2. 收银（日常售卖）

### 2.1 商品管理

路径：**商品管理**

1. 新增商品：名称、价格、单位、分类、所属场馆（可选）。  
2. 可上下架；下架后收银台不可选。  
3. 无库存概念，只记名称与价格。

### 2.2 收银台

路径：**收银台**

1. 选择场馆。  
2. 点击商品加入清单，调整数量。  
3. 确认下单 → 进入收款页。  
4. 扫码支付为占位提示；正式收款点 **现金支付**。  
5. 支付成功后可在销售报表查看。

### 2.3 销售报表

路径：**销售报表**

- 老板：看全店当日汇总。  
- 店员：只看自己操作的销售。  

订单明细页：`/sales/orders`（可从业务流程进入；菜单以日报为主）。

---

## 3. 员工管理（仅老板）

路径：**员工管理**

1. **新增店员**：登录账号、初始密码（≥6 位）、姓名、手机（可选）。  
2. **编辑**：改姓名/手机/备注（不可改老板账号角色）。  
3. **停用 / 启用**：停用后无法登录；历史单据保留。  
4. **重置密码**。  

店员创建后，用新账号登录即可收银、订场。

---

## 4. 片场管理

路径：**片场管理**

1. 选择所属场馆，填写片场名称（如「1号全场」）、类型（全场/半场）、编号、排序。  
2. 停用后不可再被新订场选中。  
3. 老板与店员均可维护。

---

## 5. 球队管理

路径：**球队管理**

1. **新增**：队名、队长、电话、**对接员工（必选）**、备注。  
2. **换对接人**：点「换对接人」→ 选新员工 → 可填原因；会写审计日志。  
3. **详情**：基本信息、战绩摘要、近期订场、审计记录。  
4. 停用球队后不可再被新订场选中。  

说明：历史订场上的「对接人」是下单时快照，换对接人**不会**改历史单。

---

## 6. 订场

### 6.1 订场日历

路径：**订场日历**

1. 选片场 + 日期。  
2. 绿色格可订；红色/占用格不可点（会提示已占用单号）。  
3. 点空闲格 → 新建订场：  
   - **球队**：选球队后只读展示对接员工；  
   - **个人**：填联系人姓名、电话。  
4. 开始/结束时间须落在半小时（如 18:00–19:00）；可改金额与备注。  
5. 确认后写当前登录人为**操作员工**。

冲突时会提示「与订场单 xxx 时间冲突」。

### 6.2 订场列表

路径：**订场列表**

- 按日期/状态筛选。  
- **完成**：已预订 → 已完成。  
- **取消**：仅已预订可取消，取消后释放时段。  
- **录赛果**：未录过且未取消的单可录入。  

---

## 7. 赛果与排行

### 7.1 录赛果

路径：**赛果管理**，或从订场列表点「录赛果」

1. 选择主队、客队（都必须是系统内球队，且不能相同）。  
2. 填写比分；结果自动判定胜/负/平。  
3. 同一订场只能录一次；需要改正用「修正」。  
4. 录入后订场会变为已完成（若仍是已预订）。

### 7.2 球队排行榜

路径：**球队排行榜**

- 按积分（胜 3 / 平 1）→ 净胜分 → 得分 排序。  
- 仅统计已录入赛果的场次。

---

## 8. 业绩

### 8.1 我的业绩

路径：**我的业绩**

查看本人：收银笔数/金额、操作订场、对接订场（可按日筛选）。

### 8.2 员工业绩（仅老板）

路径：**员工业绩**

全员排行：收银 + 操作订场 + 对接订场。

口径：

| 指标 | 归因 |
|------|------|
| 收银 | 操作人 |
| 操作订场 | 下单人 |
| 对接订场 | 订场单上的对接快照（仅球队订场） |

取消的订场不计入业绩。

---

## 9. 推荐日常顺序（新店）

1. 老板登录 → 建店员账号  
2. 片场管理：按场馆建片场  
3. 商品管理：录入饮品等  
4. 球队管理：建队并指定对接人  
5. 订场日历：开始接预约  
6. 赛后：订场列表录赛果 → 看排行榜  
7. 日终：销售报表 + 员工业绩

## 10. 平台 Admin（开户与配置）

地址：http://localhost:3000（`admin` / `123456`）

完整步骤见：[操作手册-平台Admin.md](./操作手册-平台Admin.md)。

摘要：

1. **商户开户**：商户信息 + 老板账号；可勾选首场馆  
2. 用老板账号登录本商户端验证  
3. 详情中可配置功能开关、绑定小程序（供 C 端）  
4. **停用商户**后，本端所有账号将无法登录（提示商户已停用）

## 11. 常见问题

| 现象 | 处理 |
|------|------|
| 登录失败 | 确认账号未停用；商户未被平台停用；密码正确；后端已启动 |
| 提示「商户已停用」 | 联系平台 Admin 将商户状态改回 ACTIVE |
| 某模块接口 40303 | 平台关闭了对应功能开关（收银/订场/球队等） |
| 订场提示冲突 | 换时段，或先取消原「已预订」单；过期单不占场 |
| 无法取消订场 | 已完成或已有赛果不可取消 |
| 店员看不到员工管理 | 正常，仅老板可见 |
| 对接业绩为 0 | 确认是球队订场且自己是下单时的对接快照人 |
| 扫码支付不可用 | 预期：Phase 1 用现金；扫码为占位 |

更细的启停与排错见：`运维手册-本地部署.md`。
