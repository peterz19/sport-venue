## 2. 验证步骤（摘要）

1. 执行 `V4__org_booking_module.sql`（若尚未建表）  
2. 启动 venue（`local`）+ merchant（`:3001`）  
3. 老板建店员 → 店员登录权限隔离  
4. 建片场 → 重叠订场失败 → 取消后再订成功  
5. 球队对接店员 B，老板 A 下单 → A 操作 +1、B 对接 +1；换对接后旧单仍算 B  
6. 录赛果 → 排行榜胜场/积分变化  

操作细节见：`../操作手册-商户端.md`。
