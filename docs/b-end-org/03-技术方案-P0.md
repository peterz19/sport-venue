# 组织经营 · 技术方案（P0 先行）

> 对应产品：`docs/b-end-org/01` / `02`  
> 本阶段：**P0 员工账号 + 收银按人业绩（已落地）**  
> P1+ 片场/球队/订场另文扩展

---

## 1. 目标

1. 商户老板可管理本商户员工账号（增改、停用、重置密码）  
2. 老板 / 店员用各自账号登录商户端  
3. 收银继续记 `operator_id`；按员工看收银业绩  
4. 店员只看自己；老板看全部  

角色映射（复用现有枚举，不新建表）：

| 产品角色 | `User.userType` |
|----------|-----------------|
| 老板 OWNER | `B_MERCHANT` |
| 店员 STAFF | `B_STAFF` |
| 停用 | `status = INACTIVE` |

---

## 2. API（均需 JWT，前缀 `/business`）

### 员工

| 方法 | 路径 | 权限 |
|------|------|------|
| GET | `/business/staff` | 老板 |
| POST | `/business/staff` | 老板 |
| PUT | `/business/staff/{id}` | 老板 |
| PUT | `/business/staff/{id}/status` | 老板 |
| PUT | `/business/staff/{id}/password` | 老板 |
| GET | `/business/staff/options` | 老板+店员（下拉：在职员工） |

创建员工：固定 `userType=B_STAFF`，`merchantId=当前商户`。  
禁止通过本接口创建第二个老板账号。  
禁止停用自己（老板）。

### 业绩（收银）

| 方法 | 路径 | 权限 |
|------|------|------|
| GET | `/business/performance/me` | 全部 |
| GET | `/business/performance/staff` | 老板（排行） |
| GET | `/business/performance/staff/{id}` | 老板或本人 |

查询参数：`date`（单日）或 `dateFrom`+`dateTo`；默认今天。

返回字段（收银部分）：`orderCount`、`salesAmount`、`totalQty`；预留 `bookingOperate*` / `bookingLiaison*` 为 0。

### 销售报表收紧

`GET /business/sales/daily/*`、`/business/sales/orders`：店员仅本人 `operator_id` 数据；老板不变。

---

## 3. 前端

- 菜单：员工管理（老板）；我的业绩；员工业绩（老板）  
- `localStorage.merchantInfo` 增加 `userType`、`realName`（登录已有则沿用）  
- 路由守卫：非老板访问员工管理 / 员工业绩 → 回收银台
