## 4. 关键校验规则（开发必遵）

1. 订场时段：`start/end` 必须落在半小时点；时长 ≥ 30 分钟且为 30 分钟整数倍。  
2. 冲突：同片场时间重叠 + 占用中状态 → 拒绝。  
3. TEAM 订场：必须有 team；下单瞬间拷贝球队当前 `liaison_*` 快照。  
4. PERSON 订场：无 liaison；不计入对接业绩。  
5. 赛果：home/away 均为本商户下 ACTIVE 球队；不能相同；必须挂已存在订场单。  
6. 换球队对接人：只改 team 当前值；历史 booking 快照不变；写 TeamAuditLog。  
7. 店员业绩接口：强制 `staff_id = 当前用户`；老板可查任意员工。

## 5. 分期任务表

### Phase 0 — 员工账号与收银业绩（先落地组织）

| 任务 | 说明 |
|------|------|
| 员工管理页 | 老板增员、停用、重置密码 |

**验收：** 两名店员账号分别收银，老板能看两人销售额差异。

| 任务 | 说明 |

| 任务 | 说明 |

**验收：** A 操作、球队对接 B → A 操作单 +1，B 对接单 +1；换对接人后旧单仍算 B。
