# 操作手册 · 平台 Admin

> 适用：平台运营 / 实施  
> 地址：http://localhost:3000  
> 账号：`admin` / `123456`（仅 `ADMIN` 可登录）

---

## 1. 登录

1. 打开 Admin 登录页。  
2. 使用平台管理员账号；商户老板账号会被拒绝（提示去商户端）。  
3. 登录失败时检查：后端已启动、账号类型为 ADMIN、密码正确。

---

## 2. 商户列表

路径：**商户管理**（`/merchant/list`）

| 操作 | 说明 |
|------|------|
| 刷新 | 重新拉取商户列表 |
| 商户开户 | 创建商户 + 老板；可填可选首场馆 |
| 编辑 | 改名称、联系人、地址等 |
| 停用 / 启用 | 停用后该商户下老板/店员**无法登录** |
| 场馆 | 跳转场馆列表并带上 `merchantId` |
| 详情 | 打开右侧抽屉（开关 / 微信 / 审计） |

---

## 3. 商户开户

1. 点「商户开户」。  
2. **商户信息**：名称必填；编码可空自动生成。  
3. **老板账号**：登录名、密码（≥6）、姓名必填。  
4. **可选首场馆**：填名称+地址则同事务创建场馆；不填则跳过。  
5. 成功后提示商户 ID 与老板用户名；用该账号登录 http://localhost:3001 验证。

---

## 4. 商户详情（SaaS 配置）

在列表点「详情」：

### 4.1 概况

- 状态、老板账号、场馆数/员工数  
- 小程序 / 公众号是否已绑定  

### 4.2 功能开关

| 开关 | 作用 |
|------|------|
| 收银 | 关闭后商品/销售 API `40303` |
| 订场 | 关闭后片场/订场 API `40303` |
| 球队赛果 | 关闭后球队/赛果 API `40303` |
| C 端 | 关闭后无法 C 登录 |
| 充值 | 关闭后无法 C 充值 |

保存后立即生效（已登录 token 下次调对应接口时拦截）。

### 4.3 平台抽成（A1 台账）

路径：**平台抽成**（`/commission/list`）

1. 为商户设置抽成比例（如 3%）、是否计入微信/支付宝/现金  
2. 商户线上支付成功后自动累计「未结抽成」（默认不计现金；真支付前联调可临时打开「计现金」）  
3. 日结/月结/年结/自定义账期 → 生成**结算快照** → 未结清零，历史保留  
4. 通道手续费（微信/支付宝）不在此台账；此处仅为平台佣金应收  

详见：`b-end-sales/04-付款码被扫支付设计.md` §15.8。

### 4.4 绑定小程序

1. 填写微信小程序 **AppId**。  
2. 填写 **AppSecret**（仅写入，列表/详情不回显明文）。  
3. 保存成功后状态为已绑定。  
4. C 端用该 AppId 调 `/c/auth/wx-login`（本地 mock 时 `code` 任意非空即可）。

同一 AppId 不可绑到两家商户。

### 4.5 审计

展示近期开户、启停、绑微信、改开关等操作记录（不含密码/Secret）。

---

## 5. 场馆管理

路径：场馆列表  

- 可从商户详情/「场馆」按钮带 `merchantId` 筛选。  
- 平台代建场馆属于该商户；商户端「我的场馆」可见。

---

## 6. 常见问题

| 现象 | 处理 |
|------|------|
| 商户账号能开户但登录商户端失败 | 查商户是否被停用；查老板 `userType`/`merchantId` |
| C 登录提示未配置 AppId | 先在详情绑定小程序并保存 Secret |
| C 登录提示功能未开通 | 打开「C 端」开关 |
| 停用后仍能操作 | 确认对方走的是 `/business/**`；过滤器会拒绝非 ACTIVE 商户 |

更完整的隔离与 API 说明见：`00-技术总览.md`、`saas/00-SaaS完整设计.md`。
